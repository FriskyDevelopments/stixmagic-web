# Code Pup brand kit 1.0

Identity anchor: the supplied hot-magenta Code Pup artwork, preserved in `reference/code-pup-original.jpg`. The brandbook develops its angular silhouette, black matrix-green goggles, amber eye, cyan code pen, condensed display type, and amber square stop. The reference remains the original raster lockup; no vector master or exact wordmark font is implied.

## Files

- `status/`: four transparent 192 x 192 PNGs, display at 64 x 64.
- `status-small/`: 96 x 96 PNGs, display at 32 x 32.
- `status-master/`: 768 x 768 PNGs for large previews and print.
- `tokens.css`: working brand colors, semantic signals, and system font stacks.
- `manifest.json`: dimensions, byte sizes, alpha checks, and SHA-256 hashes.
- `GENERATION.md`: reproducible creative prompts and export notes.
- `github-usage.md`: native Markdown layout and state mapping.

Each PR-sized PNG is approximately 13 KB. Status text stays outside the image. The matrix-green visor is part of the character in every state; only a separate approval badge and an explicit label communicate approval.

Status files are reviewing, approved, changes-requested, and blocked. Match the label to actual state. A completed review with no findings is not automatically an approval. Preserve neutral states such as paused, ignored, and skipped draft in text.

Static PNGs are the default. At most one optional GIF may occupy the Verdict slot, with a static alternative. This kit contains no GIF. Original Telegram emoji packs are a separate delivery surface.

The original supplied artwork and new status derivatives are included for the requested Code Pup brand use. No third-party font files or license grant is bundled.
